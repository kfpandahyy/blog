# OceanBase AI 功能全景：存量能力盘点、2026 年新增清单与未来趋势判断

> 一句话结论：OceanBase 的 AI 路线比多数厂商激进一层——不止给内核加向量索引，而是直接发布 AI 原生的 seekdb（带毫秒级 `FORK DATABASE` 数据沙箱），再把湖库一体架构升级为"AI 数据库"叙事，配齐引擎（Lakebase）、治理（DataStudio）、入口（DataPilot）三层产品。2026 年是它的"AI 产品化元年"：湖库一体 AI 数据库 6 月发布、4.4 LTS 商业化、DataPilot 持续月更、AI 一体机上市、入选 Forrester 多模数据平台 Wave 唯一中国厂商。

**TL;DR**

- AI 能力分七块：内核向量检索（HNSW 全系 + IVF）、全文索引（IK 中文分词 + BM25）、标量/向量/全文混合检索、seekdb（AI 原生 + 毫秒级数据沙箱）、MCP Server（2026 密集集成 IDE）、Lakebase/DataStudio/DataPilot 产品体系、AI 一体机
- 2026 年新增：4.4 商用 LTS（2-2）、湖库一体 AI 数据库（6-29）、DataPilot V0.18（7-16）、通信 AI 一体化方案（9-22）、AI 一体机（年内）、Forrester Wave 入选（7-13）
- 差异化王牌：`FORK DATABASE ... TO ...` 毫秒级克隆整库（内核级 COW），`MERGE TABLE` 合并回主线——这是 Agent 沙箱场景目前业内最完整的库级分叉语义
- 风险：宣称数字多为厂商口径；seekdb 与 OceanBase 主品牌双线并行，长期收敛路径未明

## 一、AI 功能全景：七块能力

### 1. 内核向量检索（自 4.3.3 起内建）

- **数据类型**：`VECTOR(dim)` 最大 16,000 维 float 稠密向量；支持稀疏向量
- **索引全家桶**：HNSW（内存索引）、HNSW_SQ、HNSW_BQ（RabitQ 量化，官方宣称亿级向量索引内存开销降至传统方案约 5%）；IVF/IVF_SQ/IVF_PQ（实验特性，磁盘索引）；索引列最大 4,096 维；底层集成蚂蚁自研 VSAG 向量算法库
- **距离**：L2、内积、余弦
- **性能口径**：VectorDBBench 超 PGVector、Elasticsearch；ANN-Benchmarks 960 维 GIST 数据集表现优异——均为厂商口径，无独立复现
- **内存治理**：`ob_vector_memory_limit_percentage` 控制向量索引内存占比；4.4.1 起改为默认启用 + 自适应（8GB 以下租户 40%，以上 50%），不再需手工开启

### 2. 全文索引

- 内置 **IK 中文分词器**（max_word / smart 双模式），支持自定义词典表
- 自然语言模式 + 布尔模式（`+` 包含 / `-` 排除），BM25 相关性打分
- 企业级功能支持分区表（索引与分区数据就近存储）；多索引 OR 查询走 union merge 优化
- 官方实测口径：中文布尔查询 0.03s vs `LIKE` 模糊匹配 0.08s

### 3. 混合检索（核心卖点）

- 自 4.3.5 起支持标量 + 向量混合检索，执行期**自适应选择前过滤 / 迭代式过滤**算法，优化器按标量与向量的过滤性代价选计划
- 同一张表可同时建普通索引、全文索引、多值索引、向量索引，一套数据应对多路查询
- seekdb 把混合检索推到语义层：一条 SQL 内 `MATCH(content) AGAINST(...)`（全文）+ 向量距离排序 + 标量过滤，统一**下推到同一执行计划**，客户端不再做 N+1 合并

### 4. seekdb：AI 原生数据库（2025-11-18 开源）

- 定位："不是传统数据库的功能叠加，而是专为 AI 时代重构"，继承 OceanBase 代码与设计理念，更轻量，可嵌入式、单节点、分布式三形态
- **数据沙箱（差异化王牌）**：`FORK DATABASE prod TO staging` 基于全局一致时间点**毫秒级克隆整库**（内核级 copy-on-write，非应用层保存/恢复）；Agent 在沙箱里随便写、随便破坏，`MERGE TABLE` 合并成果回主线，或 `DROP DATABASE` 一键丢弃
- 混合搜索一条 SQL 完成；兼容 Hugging Face、LangChain 等 30+ AI 框架；MySQL 协议 + 完整 ACID
- 云服务 `d0.seekdb.ai`：一条 curl 命令起实例，免注册、免信用卡、免费 7 天——即"秒级启动"的官方答案
- 官方博客口径：Milvus 10.7 倍 QPS 背后的架构（未独立验证）

### 5. MCP Server 与 Agent 接入

- `github.com/oceanbase/mcp-oceanbase`，2025-04-30 起支持，可执行 SQL，私有化与 OB Cloud 均可用
- 2026 年密集出集成文档：Google GenAI Toolbox 免编程构建（3-18）、Trae IDE（4-09）、AWS Kiro agentic IDE（5-27）

### 6. 产品体系：Lakebase / DataStudio / DataPilot（2026-06-29 发布）

- **Lakebase**（引擎层）：结构化、非结构化、向量数据统一管理与检索
- **DataStudio**（治理层）：数据接入、加工、编排、语义建模、Agent 协作，把数据资产变成可调用的数据服务
- **DataPilot**（入口层）：自然语言生成分析报告、数据看板、可信答案——独立产品在 2026 年持续月更（V0.18，2026-07-16：企业微信登录、移动端分析入口、**文档分类器**（样本管理→训练→批量推理→结果回流闭环）、Agent 工作台 + 代码沙箱（2GB/1核 默认配额）、MCP 入口）
- 厂商口径：整体 TCO 较传统多系统方案降 30%-50%；已在蚂蚁阿福（1 亿用户健康 AI）、灵光（累计数千万"闪应用"，千万级 Agent 并发验证）落地

### 7. AI 一体机（软硬一体，2026 年内上市）

- 单机运行满血 DeepSeek R1/V3 671B、Qwen3-235B/72B/30B，宣称性能媲美集群方案
- "以存换算"：存算协同 + 智能缓存融合 GPU/CPU/内存，GPU 开销降 10 倍、大规模并发推理性能提升 10 倍（厂商口径）
- 内置 OB MaaS 智算模型服务平台 + PowerRAG 应用引擎；开放 API，兼容 OpenAI 生态
- 一体机产品线 2026-08-06 发 V5.0.1，AI 一体机作为独立产品线运营

## 四、未来趋势判断

以下分"事实延伸"与"推断"两档，推断处单独标注。

### 1. 湖库一体成为主叙事，"AI 数据库"对标国际口径（事实延伸）

OceanBase 已把话术从"分布式数据库"切换为"湖库一体 AI 数据库"：数据湖的开放存储 + 数据库的事务分析 + 多模处理统一到单一强一致底座。Forrester 多模数据平台 Wave 的入选给了这套叙事国际背书。预计 2027 年产品材料会全面 Lakebase 化，OceanBase 品牌逐渐退到引擎层。

### 2. 内核级数据沙箱是差异化王牌，Agent 平台是首要目标场景（事实延伸 + 推断）

`FORK DATABASE` 毫秒级整库克隆 + `MERGE TABLE` 回并，是目前数据库厂商里对"Agent 沙箱/分支环境"语义支持最完整的实现（多数厂商停留在实例级快照或分钟级分支）。**推断**：2027 年这一能力会从 seekdb 向 OceanBase 主内核和 OB Cloud 下沉，成为 Agent 平台选型时的核心竞争点；同时会引出与 Neon 式分支相似的计费模型创新（沙箱按存活时长/写放大计费）。

### 3. seekdb 与主品牌双线的收敛问题（推断）

seekdb 开源、轻量、AI 原生；OceanBase 4.4+ 企业级、全功能。两条线共享内核但品牌、部署形态、目标用户不同。社区已出现"该选哪个"的困惑。**推断**：12 个月内 seekdb 要么并入主品牌作为"AI 版"发行线，要么明确限定为开发者/边缘场景，长期双轨的维护成本太高。

### 4. 蚂蚁生态是最大杠杆，也是最大边界（事实 + 推断）

OceanBase AI 数据库在 WAIC 上被定位为蚂蚁技术基座组件，阿福、灵光是首发验证场景。**推断**：金融、政务、运营商等高合规行业会是 2027 年主攻市场（一体机 + 私有化 + 行业方案三件套已备好）；代价是国际化与通用开发者生态的推进速度继续慢于产品节奏。

### 5. 竞争坐标（推断）

- 对 TiDB/PingCAP：双方都在讲"All-in-One 数据底座"，TiDB 强在 MySQL 生态与 TiDB X 云的弹性，OceanBase 强在内核级沙箱、量化索引（RabitQ）和蚂蚁场景背书；向量能力两家都仍在"公测/迭代"状态，都不是 GA 态度
- 对 Doris/StarRocks：分析侧被 Doris 4.x 的"向量+全文+AI 函数"贴身紧逼，OceanBase 的反击是把战场拉到事务一致性与湖库一体
- 对 PG 生态（pgvector/Neon/Supabase）：开发者心智仍处于劣势，seekdb 的 curl 起实例 + 三行代码是在补这门课

### 6. 风险清单

- 性能与 TCO 数字几乎全为厂商口径，公开可复现的基准少
- DataPilot 与类似 NL2BI 产品（阿里 DS-ChatBI、各种 ChatBI 创业团队）同质化风险
- 一体机依赖硬件供应链与信创周期，毛利和交付节奏不确定
