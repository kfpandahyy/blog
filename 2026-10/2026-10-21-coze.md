# 扣子（Coze）调研：字节 Agent 平台的版本演进、生态版图与锁定风险

> 一句话结论：扣子是字节跳动的 AI Agent 开发平台，2024 年初上线以来经历四次定位重构——从聊天机器人搭建工具（1.x）到通用 Agent 产品（扣子空间）到"职场伙伴"（2.0）再到多人多 Agent 协作操作系统（3.0），当前是国内用户量最大的低代码 Agent 平台。它的结构性优势是字节生态分发（豆包/飞书/抖音渠道一键发布）和免费额度策略；结构性风险是资产锁定、变现渠道受限，以及 2026 年 8 月扣子团队并入豆包体系后产品线定位的不确定性。

**TL;DR**
- 版本线：2024 年初国内上线 → 2025-04 扣子空间（通用 Agent，MCP）→ 2026-01-19 扣子 2.0（Agent Skills/Plan/Office/Coding 四件套）→ 2026-06 扣子 3.0（多人多 Agent 项目空间、云端+本地双部署）→ 2026-08 团队并入豆包体系
- 功能面：零代码 Bot 搭建、可视化工作流编排、800+ 插件、知识库、多模型（豆包/DeepSeek/Kimi/GLM）、MCP、Responses API、技能商店、Vibe Coding 编程、接入 Seedance 的视频创作 Skill
- 生态规模（官方口径）：超 1000 万真实开发场景、全球注册开发者超 300 万、日均活跃智能体 80 万+、近 40% 部署在字节系产品
- 定价：个人免费版（每日约 500 次调用额度）→ 个人进阶约 39.9 元/月 → 企业标准版 ¥980/月、旗舰版 ¥8,980/月（2026-07-14 调价后，接近翻倍）
- 关键限制：智能体资产不可迁移、变现仅限字节生态（不支持微信支付）、创作者分成约 70%
- 最大变量：2026-08-25 豆包工作发布，TRAE 与扣子团队并入豆包体系，扣子从独立产品线变为豆包体系内的开发层

## 一、速览

| 项 | 内容 |
|---|---|
| 出品 | 字节跳动（Seed 团队体系，2026-08 起并入豆包体系） |
| 产品 | 国内版 coze.cn / 海外版 coze.com（2023 年 11 月海外先行，国内 2024 年初上线） |
| 定位 | 零代码/低代码 AI Agent 开发平台，当前形态：Agent 原生协作操作系统 |
| 底座模型 | 国内：豆包、DeepSeek、Kimi、GLM、通义千问；海外：GPT-4o、Gemini Pro 等 |
| 开源面 | Coze Studio（Apache 2.0）+ Coze Loop + Eino（Go LLM 框架）+ veRL（RLHF 框架） |
| 发布渠道 | 豆包、飞书、微信/公众号、抖音、网页；海外 Discord、Telegram、Slack |
| 商业化 | 个人订阅 + 企业版按席位订阅 + 资源点计费；2026-07 企业版调价近翻倍 |

## 二、版本演进：四次定位重构

| 时间 | 节点 | 定位变化 |
|---|---|---|
| 2024 年初 | 国内版上线 | 聊天机器人搭建工具（提示词 + 插件 + 知识库 + 工作流四件套） |
| 2024-10 | Bot 升级为"智能体" | 从问答工具转向 Agent 定位，强化工具调用与任务执行 |
| 2025-02 | 接入 DeepSeek-R1/V3 | 多模型策略打开，摆脱单绑豆包的形象 |
| 2025-04-18 | 扣子空间（Coze Space）内测 | 通用 Agent 产品：专家 Agent 体系、探索/规划双模式、MCP 协议、飞书/高德等工具接入 |
| 2025-12 | 扣子编程 | Vibe Coding 范式，自然语言开发应用并一键部署 |
| 2026-01-19 | 扣子 2.0 | "职场伙伴"定位：**Agent Skills**（场景最佳实践封装 + 技能商店）、**Agent Plan**（长期目标拆解、跨周/月执行）、**Agent Office**（Word/Excel/PPT 深度处理）、**Agent Coding**（云端 Vibe Coding 平台） |
| 2026-06 | 扣子 3.0 | 多人多 Agent 协作项目空间、编程/视频专项项目、云端+本地双部署（Claude Code/Codex CLI 接入）、三端协同 |
| 2026-07-14 | 企业版调价 | 标准版 ¥498→¥980/月，旗舰版 ¥5,980→¥8,980/月，理由是 3.0 企业能力（多 Agent 协作、模型自定义、项目空间、数据隔离） |
| 2026-08-25 | 组织调整 | 豆包工作（AI 办公智能体）发布，TRAE、扣子团队并入豆包体系 |

这条线的读法：**扣子每 6-12 个月重定义一次自己**，从"造 Bot 的工具"到"通用 Agent"到"职场伙伴"到"协作操作系统"——跟随行业范式从对话 → Agent → 多 Agent 协作的节奏。同时注意组织信号的拐点：并入豆包体系意味着字节把"开发平台"和"办公 Agent 产品"收成一条线，扣子未来是豆包的能力供给层还是独立产品线，官方尚未给出清晰边界。

## 三、功能全景（3.0 形态）

**搭建层**：可视化拖拽编排，提示词、插件、知识库、工作流四要素。评测口径中从注册到可用客服 Agent 约 15 分钟上手，国内平台中上手门槛最低档。

**能力层**：
- 插件市场 800+（搜索、天气、股票、翻译、图片生成等），支持 MCP 插件接入第三方工具
- 技能商店（2.0 起）：把"场景最佳实践 + 工具调用逻辑 + 质量检查"封装为可安装模块（法律类案检索、投资知识库、营销文案框架等），支持开发者上传分成
- 多模型切换：豆包主力，DeepSeek/Kimi/GLM/通义可选；海外版接 GPT-4o/Gemini
- Responses API、异步执行工作流、语音合成音色等企业向接口能力

**协作层（3.0 核心增量）**：
- 项目空间内多人 + 多 Agent 分工（调研 Agent、文案 Agent、剪辑 Agent 同上下文流转）
- 云端 + 本地双部署：本地 Claude Code、Codex CLI 等一键接入项目空间
- 网页 + 桌面 + App 三端协同

**垂直专项**：
- 扣子编程：代码编写、调试、版本迭代、一键部署
- 视频创作：接入 Seedance 的视频生成管线（剧本/分镜/配乐/剪辑全流程，音画同步优化）

**发布层**：一键发布到豆包、飞书、微信/公众号、抖音、网页；海外渠道 Discord、Telegram、Slack。近 40% 的智能体部署在字节系产品内（2025 年底口径）。

## 四、生态与商业化

**规模数据（均为官方或媒体转述口径）**：累计超 1000 万真实开发场景（2.0 发布时）、全球注册开发者超 300 万、日均活跃智能体 80 万+。

**定价**（各渠道口径存在差异，以官网实时为准）：

| 档位 | 价格 | 权益要点 |
|---|---|---|
| 个人免费版 | ¥0 | 基础智能体、有限工作流、每日约 500 次调用额度，原型验证够用 |
| 个人进阶版 | 约 39.9 元/月 | 私有知识库、更多工作流与额度（渠道另见 9.9/30 元报价） |
| 企业标准版 | ¥980/月（2026-07-14 起） | 调价前 ¥498；含更多席位与月度积分 |
| 企业旗舰版 | ¥8,980/月（2026-07-14 起） | 调价前 ¥5,980；3.0 企业能力全量 |

**变现机制（对创作者）**：技能/智能体可在 Coze 商店按次或订阅售卖，创作者分成约 70%——但仅限字节生态内变现，且不支持微信支付（仅支付宝原生支付或合作渠道）。

## 五、优势拆解（结构性）

1. **分发渠道是别人复制不了的资产**。做好的 Agent 一键进豆包（亿级 C 端）、飞书（企业办公入口）、抖音（内容场景），获客成本与独立平台不在一个量级。对创作者，这是"做完就有人用"；对企业，这是"渠道即服务"。
2. **免费额度策略精准打 MVP 验证场景**。每日约 500 次调用对原型验证和小规模部署免费够用，把竞品（Dify 等需自行承担模型 API 成本）的试错门槛直接归零。
3. **产品迭代速度 + 生态联动**。从 1.x 到 3.0 两年四改定位，且与字节模型（豆包）、视频（Seedance）、办公（飞书）能力同步联动——视频创作 Skill 直接接 Seedance 就是"模型层创新即刻产品化"的样本。
4. **开源面意外宽**。Coze Studio（Apache 2.0）可私有化部署、对接内部模型（Llama/Qwen/ChatGLM），配套的 Eino、veRL 也开源——对强合规行业（金融/政务/医疗）给了自托管退路，这是 Dify 传统阵地。
5. **上手成本国内最低档**。模板引导 + 拖拽编排，非技术人员可独立完成客服/内容类 Agent，匹配"人人都是开发者"的扩张叙事。

## 六、主打场景与非目标场景

**场景一：字节生态内的自动化**。飞书审批流机器人、抖音评论区运营助手、豆包插件——深度集成零摩擦，这是扣子的主场。

**场景二：Agent MVP 快速验证**。免费额度 + 15 分钟上手 + 多渠道试发，适合验证"这个场景值不值得做成 AI 应用"。

**场景三：内容生产流水线**。自媒体矩阵（文案 Agent + 排版 Agent + 视频 Skill 接 Seedance）、电商素材批量生成，复用字节内容生态工具链。

**场景四：强合规行业的私有化 Agent**。Coze Studio 开源版自托管，数据不出内网，对接私有模型。

**非目标场景**：
- 跨生态部署（微信生态外的主流渠道、独立 App 深度集成）——渠道能力以字节系为圆心衰减
- 资产要求可迁移的长期工程——知识库、工作流、提示词体系沉淀在 Coze 内，迁出成本随规模递增
- 复杂多 Agent 系统的精细编排——3.0 的多 Agent 协作是项目空间级分工，不是 LangGraph 级别的图编排与状态机控制
- 依赖微信支付的 C 端付费场景——平台级不支持

## 八、风险与限制

1. **锁定效应是结构性的**。智能体的工作流、知识库、插件配置沉淀在平台内，迁出即瘫痪——对把扣子当生产系统的团队，这是一个随时间增值的负债。缓释方案是开源版自托管，但 SaaS 版与开源版能力不对齐。
2. **变现天花板**。仅限字节生态内交易、不支持微信支付、平台握有流量入口——创作者商业模型的三条命脉都捏在平台手里。
3. **企业版成本陡增**。2026-07 调价近翻倍（标准版 +97%、旗舰版 +50%），对按年采购的企业是直接预算冲击；涨价锁定 3.0 能力，等于把协作能力做成付费墙。
4. **组织变动的最大变量**。2026-08 扣子团队并入豆包体系、豆包工作发布（桌面 Agent + 电脑操作 + 多智能体协作，定价 68/200/500 元/月），字节 Agent 产品线出现"平台层（扣子）+ 产品层（豆包工作）"的双层结构。短期看是协同，中长期看两者的边界、资源分配、乃至合并，都是采购决策无法排除的不确定性。
5. **多模型策略的实质**。虽然接了 DeepSeek/Kimi/GLM，但主力模型与深度优化仍在豆包；第三方模型接入的灵活度不及 Dify 一类中立平台。

## 九、同类坐标

| 平台 | 强项 | 与扣子的关系 |
|---|---|---|
| Dify（开源） | 技术灵活度、私有化、模型中立 | 技术派首选；扣子的开源版 + 字节生态是差异化对冲 |
| 腾讯元器 | 微信生态渠道 | 渠道侧正面竞争，字节系 vs 腾讯系 |
| 阿里百炼 | 企业级云集成、通义生态 | 云上企业客户竞争 |
| Copilot Studio | Microsoft 365 生态 | 海外企业市场，生态位对位 |
| n8n | 集成广度、工作流自动化 | 偏自动化层，可作扣子工作流的补充 |
| LangGraph | 代码级多 Agent 编排 | 深度工程场景的上限替代 |
| 豆包工作（字节） | C 端桌面 Agent、电脑操作 | **内部产品**，并入豆包体系后与扣子是兄弟+竞合 |

## 十、判断与建议

1. 扣子的真实定位是**字节 Agent 生态的能力供给层**：C 端流量在豆包，办公场景在飞书/豆包工作，视频在即梦/剪映，扣子负责把第三方开发者的产能接进这张网。选不选扣子，本质上是选不选字节这张生态网。
2. MVP 与字节生态内场景：直接用，免费额度足够，上手成本最低。这是扣子性价比最高的使用方式。
3. 重度生产系统：立项时把**迁出成本**写进技术选型文档——盘点哪些资产（知识库/工作流/插件链）可导出、哪些不可导出，并评估开源版（Coze Studio）与 SaaS 版的能力差是否可接受。
4. 企业采购：调价后重新核算 TCO，并把"3.0 企业能力是否被真实使用"作为续约审计项；同时跟踪扣子与豆包工作的边界政策，合并或裁剪都会改变采购前提。
5. 创作者：技能商店分成比例可以接受，但把付费用户引导至生态外的自有渠道是必修课——平台内做生意，平台规则一变你就是成本项。
